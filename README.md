# ARK-Calc &mdash; Arknights Planner & Material Engine

**ARK-Calc** &mdash; это современное, быстрое и полностью автономное веб-приложение (PWA) для планирования прокачки оперативников мобильной игры **Arknights**, точного расчета необходимых ресурсов, анализа склада и построения дерева крафта в Мастерской.

Приложение работает по принципу **Offline-First**: не требует собственного бэкенда или регистрации, сохраняет все данные пользователя локально в браузере (IndexedDB) и мгновенно пересчитывает граф ресурсов при любых изменениях.

---

## 🌟 Основные возможности

### 1. 📋 Интерактивный каталог оперативников
- **Полная база персонажей**: актуальные данные синхронизируются напрямую из upstream-репозитория Arknights (CN-база с официальными английскими именами `appellation`).
- **Мощные фильтры**: быстрый поиск по имени на английском или русском языке (с автоматической транслитерацией и популярными псевдонимами), фильтрация по редкости (1★–6★), классам (Vanguard, Guard, Defender, Sniper, Caster, Medic, Supporter, Specialist) и статусу в плане.
- **Плавная виртуализация**: список из 450+ персонажей рендерится через `DynamicScroller` с динамическим замером высоты карточек, обеспечивая стабильные 60 FPS без лагов и задержек.

### 2. 🎯 Детальный планировщик прокачки
- **Элита и уровни**: настройка текущего и целевого состояния персонажа ($E0\,L1 \to E2\,L90$) с точным подсчетом требуемого боевого опыта (EXP) и LMD.
- **Мастерство навыков (Mastery)**: независимый выбор целевого уровня скиллов (от 7 ранга до $M1 \to M3$).
- **Система модулей**:
  - Полная поддержка веток модулей: **X**, **Y**, **Δ (Delta)**.
  - Отображение аутентичных иконок экипировки и бейджей архетипов.
  - Выбор уровней модулей от 1 до 3 с учетом специфических материалов (Data Correction Blocks, Module Data Blocks).

### 3. 📦 Учет склада (Inventory)
- **Фокус на ресурсах для крафта**: фильтрация базы исключает дубликаты, токены потенциала и мусорные предметы, отображая только актуальные материалы для возвышения и модулей.
- **Категоризация по тирам**: T5, T4, T3, T2, T1, чипы классов и дуал-чипы, книги навыков, купоны и LMD.
- **Быстрый ввод и поиск**: многоязычный поиск по материалам и удобное изменение количества.

### 4. 🧮 Умный калькулятор дефицита и крафта
- **Прямой дефицит**: сопоставление суммарных потребностей плана с запасами на складе с подсветкой недостающих ресурсов.
- **Рекурсивное разложение крафта**: автоматический расчет синтеза в Мастерской (Workshop), включая сложные цепочки T5 $\to$ T4 $\to$ T3 $\to$ T2 и конвертацию чипов.
- **Защита от циклов**: встроенный детектор графовых циклов и защита от переполнения стека.

### 5. 🌐 Мультиязычность и локализация
- Официальные английские имена оперативников (Global EN) для однозначной идентификации.
- Переключение языка названий материалов (English / Русский) в настройках с сохранением выбора в `localStorage`.
- Поиск персонажей как по оригинальному английскому имени, так и по русским названиям/транслитерации (например, *«Роса»* $\leftrightarrow$ *«Rosa»*, *«Позёмка»* $\leftrightarrow$ *«Pozëmka»*, *«Вий»* $\leftrightarrow$ *«Vii»*, *«Логос»*, *«Шу»*, *«Вишадель»*, *«Кальцит»*).

### 6. 🔒 Надежность, экспорт и PWA
- **100% приватность**: ваши данные никогда не отправляются на сторонние серверы.
- **Экспорт и импорт**: резервное копирование склада и планов в JSON-файл в один клик.
- **PWA-режим**: установка на рабочий стол или смартфон как нативное приложение с кешированием ассетов для работы офлайн.

## 🚀 Установка и локальный запуск

### Требования
- **Node.js** версии 18.0 или выше
- **npm**, **pnpm** или **yarn**

### 1. Клонирование репозитория
```bash
git clone https://github.com/Migetsu/ArkCalc.git
cd ArkCalc
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере адрес [http://localhost:5173](http://localhost:5173).

### 4. Сборка для продакшена
```bash
npm run build
```
Готовые оптимизированные статические файлы будут сгенерированы в папку `dist/`.

### 5. Предварительный просмотр сборки
```bash
npm run preview
```

## 🌐 Деплой на Vercel (Хостинг)

Проект является полностью статическим приложением (SPA) и **идеально подходит для хостинга на Vercel**:

1. Запушьте проект в свой репозиторий на GitHub / GitLab / Bitbucket.
2. Перейдите на [vercel.com](https://vercel.com/) и нажмите **Add New Project**.
3. Выберите ваш репозиторий `ArkCalc`.
4. Vercel автоматически определит пресет **Vite**:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Нажмите **Deploy**.

> В репозиторий уже добавлен конфигурационный файл `vercel.json` с SPA-маршрутизацией. При деплое на Vercel проект автоматически получит бесплатный SSL-сертификат (HTTPS), благодаря чему полностью активируются функции PWA (установка приложения на телефон и ПК) и Service Worker кэширование.
